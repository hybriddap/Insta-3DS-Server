N3DS Instagram Server
=======

This was made with Flask and written in Python.

This is the server to the client 3DS application found [here](https://github.com/hybriddap/Insta-3DS).

Please note, due to hardware restrictions, with the 3DS, the server must be run over http. I am running one as a default and proof of concept [here](***REMOVED***)
